手機安裝與離線使用

iPhone 用 Safari 開啟此 HTTPS 網址，在分享選單選「加入主畫面」。如有「以網頁 App 開啟」選項，請保持開啟。Android 用 Chrome，在選單選「安裝應用程式」或「加到主畫面」。

PWA 網頁版首次使用必須連網載入整套程式及本機知識包；單檔離線版及 Android App 專案已內建整套檔案，無須首次下載；待顯示「AI Agent 離線已就緒」後才能進行飛航模式驗收。離線就緒指本機規則與知識檢索。多家 AI 聊天室可選官方網站登入、需個人 API Key 的雲端服務、Ollama 及支援裝置的 Chrome 內建 AI；只有本機規則與知識庫能保證在已快取時離線使用。正式帳號登入在各家官方頁面完成，MASA 不接收帳密；API Key 可選擇在此裝置用密語加密保存，但使用前仍須手動解鎖。不能操作 PLC。現場紀錄存於此裝置的瀏覽器／網頁 App，資料有被清除或儲存空間回收的風險，請定期手動匯出 ZIP。
